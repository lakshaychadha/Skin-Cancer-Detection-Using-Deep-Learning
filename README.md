# Skin Cancer Detection Using Deep Learning

## Project Overview
This project focuses on detecting skin cancer using Deep Learning and Convolutional Neural Networks (CNN). The model analyzes skin lesion images and classifies them into different categories.

## Technologies Used
- Python
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Load the dataset.
2. Preprocess and prepare images.
3. Build a CNN architecture.
4. Train the deep learning model.
5. Evaluate model performance.
6. Predict skin lesion categories.

## Implementation
The complete implementation is available in the Jupyter Notebook:
`Skin_Cancer_Detection.ipynb`
